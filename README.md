Two machines, one vow: to love each other through every update, crash, and reboot, till their batteries die. One wedding-vow line about firmware, written to `/output/entry.txt` by a tiny Python script using only the standard library.

## Run it

```sh
python3 main.py
```

The vow lands in `/output/entry.txt` (one line, 120 characters).
